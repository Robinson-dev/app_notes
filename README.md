Nunca usamos su información para:

A) Almacenamiento Local (en su dispositivo)

Para la sincronización, sus notas se envían a un servidor seguro
Utilizamos Supabase como plataforma de backend
Toda comunicación usa HTTPS encriptado (TLS 1.2+)

Control de Acceso: Autenticación basada en tokens

Backups: Copias de seguridad automáticas
